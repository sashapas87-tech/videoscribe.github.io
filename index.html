Облачный режим Groq — тарифы и лимиты

Groq — облачный сервис, где та же нейросеть Whisper large-v3 работает на специализированных чипах: час записи распознаётся за пару минут на любом, даже самом слабом компьютере. VideoScribe подключается к нему по вашему личному ключу с console.groq.com/keys — регистрация по почте, две минуты.

Ограничения Groq — и как VideoScribe обходит их за вас

📦

Лимит 25 МБ на запрос

Не ваша забота. Программа сама извлекает звук и режет его на 20-минутные куски по ~7 МБ, а текст склеивает со сквозными таймкодами. Видео может быть любого размера — хоть трёхчасовой вебинар на гигабайт.

⏳

Часовая квота: 2 часа аудио

Если очень длинная запись упёрлась в квоту, программа не выдаёт ошибку: показывает обратный отсчёт «ждём сброса квоты», дожидается и продолжает сама. Запустили — и ушли пить кофе.

📅

Дневная квота: 8 часов аудио

Программа сообщит об этом по-русски, а уже распознанный текст сохранит — ничего не пропадёт. Продолжить можно завтра, на платном тарифе Groq или локальной моделью.

🔐

Приватность в облаке

В облачном режиме на серверы Groq отправляется только аудиодорожка, по кусочкам. Для конфиденциальных записей используйте локальный режим — он не выходит в интернет вовсе.

Цены и лимиты Groq указаны по данным console.groq.com на июль 2026 года и могут меняться — актуальные значения смотрите на сайте Groq. Тот же ключ используется и для функции перевода транскрипта.

FAQ — проблемы и решения

Коротко о том, что может пойти не так, и как это чинится за минуту.

Windows пишет «Windows защитила ваш компьютер» +
Это стандартное предупреждение SmartScreen для любых программ без платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае» — установка продолжится. Происходит только при первом запуске установщика.
Антивирус ругается на установщик +
По той же причине — нет платной подписи. Добавьте файл в исключения антивируса. Сомневаетесь — проверьте установщик на virustotal.com перед запуском.
Чем обычная версия отличается от portable? +
Функции одинаковые. Обычная ставится установщиком VideoScribe-Setup.exe и создаёт ярлыки — удобнее для постоянной работы. Portable не требует установки: распаковали ZIP — запустили VideoScribe.exe, можно носить на флешке. Обе скачиваются бесплатно со страницы загрузки и до активации работают в пробном режиме.
Распознаёт медленно +
Три пути: 1) выберите модель поменьше (small/medium) в Настройках; 2) включите облачный режим с бесплатным ключом Groq — быстрее в десятки раз; 3) если есть видеокарта NVIDIA — напишите нам, пришлём короткую инструкцию по включению GPU-ускорения.
Какие лимиты у бесплатного ключа Groq? +
До 2 часов аудио каждый час и до 8 часов в сутки; банковская карта для ключа не нужна. Размер и длина файла не важны — программа сама режет запись на 20-минутные куски и склеивает текст. Все детали — в разделе «Облако Groq».
Программа пишет «Достигнут лимит Groq — ждём сброса квоты». Это ошибка? +
Нет, всё идёт по плану. Так выглядит пауза, когда очень длинная запись исчерпала часовую квоту бесплатного тарифа (2 часа аудио в час). Программа показывает обратный отсчёт, дожидается сброса и продолжает сама — просто не закрывайте её. А если исчерпан дневной лимит, программа скажет об этом прямо, и уже распознанный текст сохранится.
Облачный режим платный? Сколько стоит Groq? +
Бесплатного ключа хватает большинству — это до 8 часов записей в сутки. Если поток больше, у Groq есть платный тариф Developer: примерно $0.11 за час распознанного аудио, оплата по факту и заметно более высокие лимиты. Платите напрямую Groq; VideoScribe при этом остаётся разовой покупкой без подписок.
«Видео недоступно» или возрастное ограничение по ссылке +
Некоторые ролики YouTube отдаёт только после входа в аккаунт (18+, приватные, региональные блокировки). Решение: скачайте ролик любым загрузчиком и откройте в VideoScribe как файл — результат тот же.
На тишине или музыке появляется странный повторяющийся текст +
Это известная особенность всех Whisper-моделей. В VideoScribe от неё защищает VAD-фильтр (пропуск тишины) — он включён по умолчанию. Проверьте галочку «Фильтр тишины» в Настройках.
Работает без интернета? +
Да. После первой загрузки модели распознавание локальных файлов работает полностью офлайн. Интернет нужен только для YouTube-ссылок, облачного режима и перевода.
Первое распознавание долго «висит» на загрузке модели +
Модель скачивается один раз: small ~460 МБ, large-v3 ~3 ГБ — время зависит от вашего интернета. Дальше модели лежат в %APPDATA%\VideoScribe\models и загружаются мгновенно.
Нужно определять, кто из спикеров говорит +
Разметка спикеров (диаризация) есть в расширенной версии для мощных ПК — напишите нам на почту, поможем с установкой и настройкой бесплатно.

Как работает лицензия «один ключ — один компьютер» +
Ключ привязывается к вашему Machine ID (идентификатору компьютера) и работает только на нём. Поэтому при покупке мы просим прислать Machine ID из окна активации. Для второго компьютера нужен отдельный ключ — напишите нам, сделаем скидку на дополнительную лицензию.
Переустановил Windows / поменял ПК — ключ не подходит +
После переустановки системы или смены компьютера Machine ID меняется. Просто пришлите нам новый Machine ID из окна активации — вышлем обновлённый ключ бесплатно (в рамках одной купленной лицензии).
Какие требования к компьютеру? +
Windows 10 или 11, 64-бит, от 8 ГБ памяти. Для модели large-v3 локально желателен процессор посвежее — либо используйте облачный режим, он летает на любом железе.
